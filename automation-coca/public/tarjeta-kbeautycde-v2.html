📋 Cómo imprimir

  1. Tamaño: Tarjeta estándar 85×55 mm (3.35×2.17 pulgadas)
  2. Papel: Cartulina de 250-300 gsm, acabado mate o satinado
  3. Color: Rosa viejo suave (degradado #c49a8e → #b8818b)
  4. Imprimir:
    • Escala: 100% (sin ajustar a página)
    • Márgenes: 0 mm
    • Orientación: Horizontal
  5. Cortar: Usa una guillotina o cutter con regla para cortes precisos
  6. Laminado (opcional): Acabado brillante o mate para protección
Ancho: 85 mm
Alto: 55 mm
Resolución: 300 DPI (para impresión profesional)
Espacio de color: RGB (pantalla) o CMYK (impresión profesional)
