Deploy Automático

1️⃣ Tu Railway Project ID

Abre https://railway.app/dashboard
En la URL de tu proyecto verás: https://railway.app/project/xxxxx
Copia ese xxxxx

2️⃣ Tu Railway API Token

Abre https://railway.app/account/tokens
Copia el token que ves (empieza con eyJ...)

¿Qué pasa?
Copias esos 2 valores, haces click en el botón, y todo se configura automáticamente. El sitio estará en vivo en 2-3 minutos.
