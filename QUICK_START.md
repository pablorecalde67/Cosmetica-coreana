# 🚀 K-Beauty CDE - Quick Start (1 minuto)

**Tu tienda está lista. Solo falta un paso.**

## ¿Qué necesitas hacer?

Ejecuta esta línea UNA SOLA VEZ desde tu computadora:

### En macOS/Linux (Terminal):
```bash
cd Cosmetica-coreana
python3 auto_setup.py
```

### En Windows (PowerShell):
```powershell
cd Cosmetica-coreana
python3 auto_setup.py
```

Eso es todo. El script hace TODO automáticamente.

---

## ¿Qué ocurre cuando ejecutas el script?

El script `auto_setup.py`:
✅ Instala herramientas necesarias (si faltan)
✅ Se conecta a tu base de datos Supabase
✅ Crea 8 tablas de base de datos
✅ Carga 1000 productos K-Beauty
✅ Configura envío a 23 provincias
✅ Verifica que todo funciona

**Tiempo:** 2-3 minutos

## ¿Necesito Python instalado?

**Sí**, Python 3.7 o superior.

Si no lo tienes: https://www.python.org/downloads/

Asegúrate de marcar "Add Python to PATH" durante la instalación.

---

## Si algo falla

1. Verifica que tu conexión a Internet funcione
2. Verifica que tu contraseña Supabase sea correcta (está en el script)
3. Intenta nuevamente

Si hay problemas, abre: https://pablorecalde67.github.io/Cosmetica-coreana/setup-diagnostics.html

---

## Alternativa: Ejecutar desde GitHub

Si prefieres no instalar nada localmente, el setup también puede ejecutarse automáticamente via GitHub Actions:

1. Ve a: https://github.com/pablorecalde67/Cosmetica-coreana/actions
2. Selecciona "Auto Setup Database"
3. Haz clic en "Run workflow"
4. Espera 2-3 minutos
