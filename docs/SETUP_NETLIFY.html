🚀 Activar Netlify Automático

Tu sitio kbeautycde.com en vivo en menos de 10 minutos

✅ Lo que lograrás:
  • Tu sitio estará en VIVO en kbeautycde.com
  • Cada push a GitHub se despliega automáticamente
  • Cero pasos manuales después (TODO AUTOMÁTICO)

⏱️ Tiempo Total: 10 minutos

1 Obtener Token de Netlify (5 min)

Desde tu navegador en iPad:

  1. Abre: Netlify - Personal Access Tokens
  2. Haz clic en "New access token"
  3. Dale un nombre (ej: "GitHub Auto Deploy")
  4. Haz clic en "Generate token"
  5. Verás una cadena larga - CÓPIALA COMPLETA
NETLIFY_AUTH_TOKEN=eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9... (una cadena muy larga que copiarás de Netlify)
💡 En iPad: presiona y mantén → Copiar

2 Agregar Token a GitHub (3 min)

Pasos en iPad:

  1. Abre: GitHub - Repository Secrets
  2. Haz clic en "New repository secret"
  3. Nombre: NETLIFY_AUTH_TOKEN (exactamente así)
  4. Valor: Pega el token que copiaste de Netlify
  5. Haz clic en "Add secret"
Name: NETLIFY_AUTH_TOKEN Secret: (Pega aquí el token de Netlify)

3 Activar Despliegue (2 min)

Una única acción:

  1. Abre: GitHub - Actions
  2. Busca el workflow: "Auto Deploy to Netlify"
  3. Haz clic en él
  4. Haz clic en "Run workflow"
  5. Espera 2-3 minutos
✓ Esto gatilla:
  • GitHub compila tu sitio
  • Lo empaqueta
  • Lo sube a Netlify automáticamente

✅ ¡LISTO!

Tu sitio está EN VIVO en:

https://kbeautycde.com

🎉 Abre tu navegador y verás tu tienda K-Beauty completa

📅 Después de Esto: TODO AUTOMÁTICO

Cada cambio que hagas:

  1. Editas un archivo en tu código
  2. git push a GitHub
  3. GitHub Actions se ejecuta automáticamente
  4. Tu sitio se actualiza en Netlify automáticamente
  5. Cambios en vivo en 30 segundos

CERO pasos manuales después del setup inicial.

🆘 Si Algo No Funciona

Verificación Rápida:

  1. ¿Copiaste el token COMPLETO de Netlify? (debe ser muy largo)
  2. ¿El nombre en GitHub es exactamente NETLIFY_AUTH_TOKEN?
  3. ¿Esperaste 2-3 minutos después de "Run workflow"?
  4. Abre: Tu Panel Netlify y verifica que hay un deploy reciente
