Setup Vercel Deployment

Preparando deployment automático...

Agregando credenciales de Vercel a GitHub...

Tu token de Vercel ya fue compartido. Ahora necesito agregarlo como un secret en GitHub para que el deployment sea 100% automático.

Haz click en el botón de abajo. Esto abrirá GitHub y agregará el secret automáticamente.

📋 Pasos Manuales (si el botón no funciona)

1. Ve a: GitHub Secrets
2. Click en "New repository secret"
3. Name: VERCEL_TOKEN
4. Value: [[VERCEL_TOKEN]] (El token te lo dará Claude)
5. Click "Add secret"
Luego vuelve aquí y haz click en "Completado" abajo.
