⚙️ Configuración DNS para kbeautycde.com

Apuntar tu dominio a GitHub Pages (Paso final - una sola vez)

✓ Buena noticia: Tu sitio está completamente construido y listo. Solo necesitas un último paso en tu registrador de dominio.
📍 Dónde está tu dominio:

Tu dominio kbeautycde.com está registrado en Netlify DNS o tu registrador original.

Para usar GitHub Pages, necesitas actualizar los registros DNS.

🚀 Paso Único: Actualizar DNS

Opción A: Si usas Netlify DNS (Recomendado)

Accede a tu proyecto en Netlify:

  1. Ve a Settings → Domain management
  2. Busca kbeautycde.com
  3. Haz clic en Change DNS provider
  4. Selecciona Use GitHub Pages o configura manualmente (ver abajo)
  5. Guarda los cambios

Opción B: DNS Manual (Cualquier Registrador)

Si tu dominio está en Namecheap, GoDaddy, etc.

Método 1: A Records (Más rápido)

Reemplaza los registros A existentes con estos 4 valores:

Tipo Nombre Valor TTL
A @ 185.199.108.153 3600
A @ 185.199.109.153 3600
A @ 185.199.110.153 3600
A @ 185.199.111.153 3600

Método 2: CNAME (Alternativa)

O simplemente añade un registro CNAME:

Tipo Nombre Valor TTL
CNAME @ pablorecalde67.github.io 3600
⚠️ Importante: Los cambios DNS pueden tomar 15-48 horas en propagarse completamente. Tu sitio estará accesible en GitHub Pages de inmediato, pero puede que algunos ISP tarde tiempo en actualizarse.

❓ Preguntas Frecuentes

¿Puedo seguir usando Netlify?

Sí, pero no será automático. Netlify requiere autenticación en GitHub. GitHub Pages es automático sin pasos adicionales.

¿Qué pasa con mis datos en Supabase?

Supabase sigue funcionando independientemente. El sitio cargará productos tanto de la base de datos como del archivo JSON local.

¿Tengo que hacer esto en cada actualización?

No. Una vez configurado el DNS, cada push a main actualiza automáticamente tu sitio en vivo en kbeautycde.com. Sin más pasos manuales.

¿Cuánto tarda en funcionar?

GitHub Pages es instantáneo (segundos). DNS puede tardar 15-48 horas en propagarse, pero generalmente funciona en menos de 1 hora.

¿Y si algo falla?

El sitio siempre estará disponible en GitHub Pages (en github.io). Si DNS falla, puedes volver a cambiar rapidamente.
