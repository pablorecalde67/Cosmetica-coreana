🔧 Configurar K-Beauty CDE

Supabase - Base de Datos

Instrucciones:
1. Abre Supabase en otra pestaña
2. Ve a Settings → API
3. Copia Project URL y anon key
4. Pégalos aquí abajo
5. Click en "Configurar"
1
Project URL
Debe empezar con https://
Ejemplo: https://abc123.supabase.co
2
Anon Public Key
La larga cadena que empieza con eyJ
Ejemplo: eyJhbGc... (muy larga)
ℹ️ Estos datos se guardan LOCALMENTE en tu navegador. No se envían a ningún servidor.
